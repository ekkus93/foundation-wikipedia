# Read-only provisional pack CLI (PACK-004 partial)

The `wiki-pack` binary now exposes `verify <file.wpack>` and `inspect <file.wpack>` for the **provisional** `FWPACK01` unsigned envelope. Both commands stream and validate the complete container, including canonical manifest and every declared object SHA-256/length, before emitting any successful result. `inspect` additionally displays pack/project/snapshot and **claimed** origin. Neither command extracts, installs, signs, publishes, or activates anything.

Example: `cargo run --locked -p wiki-pack -- inspect ./candidate.wpack`

Exit status is 0 for verified envelope bytes, 1 for failed file access or verification, and 2 for usage errors. A verified envelope **does not establish** official publisher trust, content authority, licensing completeness, safe HTML/SVG, all mandatory offline images/math, or installed-pack readiness. An origin marked Official is explicitly an unauthenticated claim. Treat all candidate content as untrusted until the full signature and installer gates exist.

Synthetic CLI integration tests cover valid custom and claimed-official envelopes, full-payload tampering, malformed usage and missing input. This is not production pack-build/import/export, authenticated distribution or Android/offline qualification; PACK-001, PACK-004, TRUST-001 and TRUST-003 remain unchecked.
