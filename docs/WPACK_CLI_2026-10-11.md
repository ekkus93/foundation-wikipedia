# Provisional pack CLI (PACK-004 partial)

The `wiki-pack` binary exposes `verify <file.wpack>` and `inspect <file.wpack>` for the **provisional** `FWPACK01` unsigned envelope. Both commands stream and validate the complete container, including canonical manifest and every declared object SHA-256/length, before emitting any successful result. `inspect` additionally displays pack/project/snapshot and **claimed** origin. Neither inspection command extracts, installs, signs, publishes, or activates anything.

Example: `cargo run --locked -p wiki-pack -- inspect ./candidate.wpack`

Exit status is 0 for verified envelope bytes, 1 for failed file access or verification, and 2 for usage errors. A verified envelope **does not establish** official publisher trust, content authority, licensing completeness, safe HTML/SVG, all mandatory offline images/math, or installed-pack readiness. An origin marked Official is explicitly an unauthenticated claim. Treat all candidate content as untrusted until the full signature and installer gates exist.

Synthetic CLI integration tests cover valid custom and claimed-official envelopes, full-payload tampering, malformed usage and missing input. The inspect and verify commands are not a full production pack builder, authenticated distribution or Android/offline qualification; PACK-001, PACK-004, TRUST-001 and TRUST-003 remain unchecked.

## Provisional custom export (PACK-001/PACK-004 partial)

The CLI can also construct an **unsigned custom** envelope from a caller-owned, immutable directory of preverified objects:

```sh
cargo run --locked -p wiki-pack -- export-custom ./verified-objects physics enwiki 20261001 physics-definition ./physics.wpack
cargo run --locked -p wiki-pack -- verify ./physics.wpack
cargo run --locked -p wiki-pack -- inspect ./physics.wpack
```

This walks the object tree, computes source SHA-256 and length metadata, checks declared paths, rejects symlinks/nonregular files and multiply linked source files on Unix, and re-verifies every source object before streaming. Output is built in a private create-new temporary file next to the final pathname, checked again as a complete envelope, and atomically published without overwriting an existing file. An output placed inside the source tree is refused. Exit 0 indicates only that the unsigned bytes and manifest were verified; errors use exit 1 and invalid argument counts use exit 2. The object tree must not be writable by another process during export. No automatic source ingestion, rendering, media discovery, publisher signing, licensing proof, content installation, or offline-device readiness is implied.

CLI tests cover export/verify/inspect, no-overwrite preservation, invalid output placement and Unix symlink rejection. **PACK-001, PACK-004, and TRUST-003 stay open.**

## Verified but untrusted staging

```sh
mkdir -m 700 ./private-stage
cargo run --locked -p wiki-pack -- stage-unsigned ./physics.wpack ./private-stage candidate
```

The CLI reads a complete `FWPACK01` envelope, verifies the transcript and every byte, then writes a new private `candidate` directory beneath a caller-provided **owner-only** staging parent on Unix. It will not overwrite an existing candidate or mark the data installed. Missing, corrupt, symlink-redirected, modified or appended inputs fail without leaving an accepted candidate; the second-pass trailing-data check also rejects a changed input after initial verification. Both `Official` and `Custom` origin fields are *claims*, not publisher authentication.
